Aviso de privacidad

Esta página explica qué datos recoge el sitio de Condominio San Rafael y para qué.

Qué datos pedimos

El formulario de reserva pide cuatro datos:

  • nombre,
  • correo electrónico,
  • teléfono,
  • lote de interés.

No pedimos nada más. Usamos estos datos solo para responder a su solicitud de reserva o de visita.

El pago es de demostración

El flujo de pago de este sitio es una demostración. No se cobra ningún monto, no se piden datos de tarjeta y el comprobante que se genera no tiene valor legal.
