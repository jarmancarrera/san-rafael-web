# Condominio San Rafael · sitio

Sitio estático de Condominio San Rafael (Paxcamán, Petén): plan maestro, selector de 145 lotes, simulador de crédito y reserva en modo demostración.

- Publicado con GitHub Pages: https://jarmancarrera.github.io/san-rafael-web/
- Precios y pagos son de demostración (marcadores X, Y, Z; sin cobros reales).
- Generado desde el repositorio de trabajo con `02-herramientas/armar_pages.sh`; no editar aquí a mano.
